SILVER CONFORMED REFINERY PySpark + Delta MERGE

1. Sentinel Remediation

Home Credit stores "missing / never ended" as 365243.0 (1,000 years). Replaced with NULL across all employment and drawing days.

2. 27M-Row Entity Resolution

bureau_balance lacks client IDs. Silver joins it against bureau to attach SK_ID_CURR for fast data skipping.

3. Deterministic Surrogate Keys

Borrowers can pay installments in partial splits. Generated INSTALLMENT_ID via SHA-256 hash across all payment grain coordinates.

4. Physical Z-Ordering

Ran OPTIMIZE ZORDER BY (SK_ID_CURR) on every table to minimize I/O scan costs.
